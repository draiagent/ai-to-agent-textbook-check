# 讓教材讀得懂，也用得上

寫了很多，讀者卻不知道怎麼做？教材最需要檢查的，是新手在哪一步跟不上。從名詞突然出現、案例前後跳接，到同一觀念反覆說明，每個小缺口，都可能讓學習停在「好像懂了」。

「教材寫作與編輯檢查」將改稿經驗整理成 ai-to-agent-textbook-check 技能，用六個問題檢視內容：必要嗎？接得上嗎？看得懂嗎？問題解決了嗎？有回答標題嗎？前後一致嗎？讓 Agent 有依據地找出問題，再做最少必要修改。

使用時，提供教材、讀者背景與本章目標，請它找出痛點，不腦補硬塞，精簡收斂不重複，並修正上下文脈絡。保留作者觀點，也保留理解與操作所需的關鍵步驟。

每次改稿也留下修改前後與理由，將經驗累積成可重複使用的判斷，幫助老師與作者持續改善整體教材品質。

好的教材，讓人讀懂，更讓人能用。下一次交稿前，問一句：「讀完後，能實作應用嗎？」讓每次修改，都更靠近讀者真正需要的幫助。
