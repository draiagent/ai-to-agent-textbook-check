# 《書名》編輯總綱

## 讀者與目標
- 讀者是誰、已經懂什麼：
- 最初的具體痛點：
- 全書讀完能理解或完成什麼：
- 範圍與不處理的內容：

## 學習順序
| 篇／章 | 本章問題 | 讀者已知 | 本章新增理解或能力 | 主要場景 | 完成或理解的判斷方式 | 合理的下一步（可留白） |
|---|---|---|---|---|---|---|
| | | | | | | |

## 案例與依據
- 案例性質：真實／去識別化／示範。
- 已確認事實與來源：
- 待確認資訊：
- 更換場景的理由（如有）：

## 用詞與作者規則
| 用詞 | 白話定義 | 首次說明位置 | 停用或易混淆名稱 |
|---|---|---|---|
| | | | |

- 敘述語氣、圖文格式、頁碼、Logo、署名：
- 最新確認的修改與適用範圍：
